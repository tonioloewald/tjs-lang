## Minors

1. **(unverified) The `/*__tjs_shape:…*/` marker leaks into emitted JS, and the annotation goes unchecked without a warning** (`src/lang/emitters/js.ts:3627`, `src/lang/parser-params.ts`). Lens: correctness.
   - The parser writes the marker for any `{`/`[` pattern in any parameter position.
   - `destructuredShapeMarker` consumes it only for a single ObjectPattern parameter.
   - Example: `function f([a, b]: [0, 0])` emits `[ a, b ] /*__tjs_shape:[0, 0]*/` and does not check the argument; `f(['x', 2])` returns `'x2'`.
   - A second-position `{ b }: { b: 0 }` behaves the same way.
   - This contradicts the commit's claim that "the marker leaves the output whether or not checks are emitted".
   - The parameter was also unchecked at rc.7, but now a private marker ships in the output.
2. **AJS behaviour change: `({ a }: T = d)` used to be accepted with its default silently dropped, and is now refused.** Lens: correctness; verified, and reproduced against both rc.7 and HEAD.
   - `parser-params` is shared with `parseAgentSource`.
   - At rc.7, `function agent({ a }: { a: 0 } = { a: 1 })` transpiled and dropped the default.
   - At HEAD it throws "Only simple parameter names are supported".
   - The refusal is arguably more correct. But it is unpinned, and the CHANGELOG does not mention it.
3. **The .d.ts emitter ignores the new `destructuredArg` metadata.** Lens: blast-radius; verified. File: `src/lang/emitters/dts.ts`.
   - `export function area({ w, h }: { w: 0, h: 0 }): 0` generates `area(w: number, h: number): number`.
   - With a second parameter, it generates `area(w: any, h: any, k: number)`.
   - So TypeScript consumers get an error on the correct call `area({w:2,h:3})`, and their checker accepts `area(2,3)`, which the runtime now refuses.
   - The defect predates rc.7, and this release does not make it worse. The fix simply was not carried into the artifact that ships to TypeScript consumers.

## Nits

4. **`err.received` keeps the refused argument alive in the global flight-recorder ring.** Lens: blast-radius; verified. File: `src/lang/runtime.ts`.
   - The ring holds 64 entries and is mirrored to `globalThis.__tjs`. Each recorded error now holds the root argument, so a large or sensitive payload stays reachable until the ring wraps or `clearRecords()` is called.
   - Before this change, errors held only strings.
   - It is mitigated: `received` is non-enumerable, and `JSON.stringify` does not walk it (verified).
   - The retention is deliberate, but it is not documented.
