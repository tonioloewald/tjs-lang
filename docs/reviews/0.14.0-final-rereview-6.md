## Blockers

### B-1: an unbalanced `(` bypasses the new depth bound, and 64KB costs ~60–90s before fuel or timeout apply (correctness + security, **confirmed**)

- **Where:** `src/lang/parser-params.ts` `transformParenExpressions`, the non-call `(` path at about lines 847–855 and 893. The bound check is at about line 267 (`ctx.parenDepth > ctx.maxParenDepth`).
- **Mechanism:** for a `(` that does not open a call's argument list, the transform calls `extractBalancedContent(source, i+1, '(', ')')`. With no partner, that scan runs to EOF and returns `null`. The fallback does `result += source[i]; i++; continue` and never recurses, so the depth check never runs. Every later `(` rescans to EOF, which makes the pass O(N²) inside one recursion level. The removed `assertParenDepth` pre-scan counted unmatched `(` as depth and so covered this case by accident. Re-review 4's B-2 shape `'('.repeat(65536)` is itself unbalanced, so the "fix" for that finding does not cover it.
- **Measured (HEAD vs 034f2db, preprocessAgentSource):**
  - `(`×64K: about 55–91s at HEAD; about 7ms at 034f2db (refused). The time grows 4× per doubling (4K 210ms, 8K 823ms, 16K 3453ms).
  - `,(` repeated: 45s at HEAD; 5ms at 034f2db.
  - `` `${ `` + `(`×N: 80s at HEAD.
  - `(?` repeated: 56s at HEAD; 4ms at 034f2db.
  - `('` repeated: 4.4s at HEAD; 8ms at 034f2db.
  - `function f(` repeated: 4.0s at HEAD; 5ms at 034f2db.
- **End to end:**
  - `vm.run(... '('.repeat(60000) ...)` with `fuel:10, timeoutMs:1` took 70.8s.
  - `Eval` on the same input took 93.5s.
  - `runCode` on 30KB of `(` took 18.3s for about 12 fuel, and a guest can repeat that call.
  - Deployed Cloud Functions (`functions/src/index.tjs:146, 255, 388`; `rbac.tjs:235`) pass `request.data.code` to `Eval` for any signed-in user. Once they move to 0.14.0, each request pins an instance for about 90s. The comment at that call site says the super-linear issue is addressed.
- **Fix (structural, as the owner asks):** build the bracket-match table once per transform call, in **one linear stack pass that uses the transform's own tokenizer** (strings, templates with `${}`, regexes, comments). Every `(` then looks up its partner in O(1), whether balanced or unmatched. The depth bound then reads the same structure the work reads.
  - Interim only if the table has to wait: memoize "unmatched from position p". Once a scan from p hits EOF unbalanced, every later `(` at that level is unmatched too, so the rest can be emitted verbatim.
- **Tests:** add unbalanced rows to `src/admission.test.ts` SOURCES and EXPECT for every source entry (vm.run, Eval, runCode, transpileCode):
  - `(`×cap
  - `,(`×cap
  - `(?`×cap
  - `('`×cap
  - `function f(`×cap
  - `` `${ `` + `(`×cap
- **Re-review scope:** correctness + security + efficiency over the remediation diff, with the full hostile-shape grid (balanced, unbalanced, inside templates, after `}`, plus every shape under M-1) re-measured through every entry.

## Majors

### M-1: at least five more quadratic pre-fuel passes in `preprocessAgentSource` under the 64KB cap (security + efficiency + correctness, **confirmed**; existed before this commit, same class as B-1)

These were measured on HEAD at 16K / 32K / 64K. Each grows about 4× per doubling. Three exceed the admission table's `BOUND_MS = 1500` at 64KB.

| Shape | Cost at 64KB | Cause |
|---|---|---|
| one long identifier `a`×N | ~4–6s (vm.run and Eval ~3.3s at 60KB, fuel 10) | `matchAt(RE_METHOD_HEAD, source, i)` runs at **every** character, before `isInClassBody()` (parser-params.ts ~671/685). The `${ID}\s*\(` alternative re-consumes the rest of the identifier at each position. |
| `a/` repeated | ~1.8–2.9s | Every `/` runs `result.trimEnd()` over all output so far, then an unanchored `\b(return|…)\s*$` (~line 459). |
| `():` repeated | ~1.7–2.4s | Return-type extraction does a forward rescan. |
| `[` repeated | ~0.76–1.2s (Eval ~1.1s) | RE_METHOD_HEAD's computed-name alternative `\[[^\]]+\]` (line 1146) scans to EOF from every `[`. |
| `class A ` repeated | ~0.75–1.1s | The class-heritage scan looks for a depth-0 `{` all the way to EOF. |

The completeness pass also measured `function f(a: [[[[…` at 0.77s and nested `function f(a = function g(b = ` at 3.8s (ending in an acorn stack overflow). Either B-1's fix or M-1's fix may already cover these; re-measure after both.

**Fix:**
- Gate RE_METHOD_HEAD on `isInClassBody()`, and skip whole identifiers when the scan is not at a method head.
- Replace the computed-name regex with a depth-aware scanner. The B-1 match table can answer `[` too.
- Replace `trimEnd()` + `\s*$` with a bounded tail check.
- Memoize failed forward scans (class heritage, return type).
- Keep effect's `[Equal.symbol]` conversion working, and run `test:compat-scan` and `test:dogfood`.

**Decision note:** this is not a blocker because each shape costs at most ~6s under the cap, compared with ~90s for B-1. It should ride with B-1's remediation, though. The single match table fixes the bracket rows, and the brief asked for exactly this sweep.

## Minors and nits (all **unverified**; sanity-check before acting)

- **(unverified) Minor, correctness:** `src/vm/vm.ts:386`. `timeoutMs: 0` arms `setTimeout(abort, 0)`, so a compute-only agent (a `while` loop with no await) finishes successfully, contrary to the "spent deadline" comment. Fuel still bounds it. Fix: abort synchronously before the first step when `timeoutMs === 0`, and add a pure-compute row to the `timeoutMs: 0` tests.
- **(unverified) Minor, security:** `src/vm/admission.ts:85`. `maxSourceBytes: 0` means *unlimited*, while `timeoutMs: 0` now means *expired*, so zero fails open on one budget and closed on the other. A host that subtracts down to 0 lifts the cap and exposes B-1/M-1 without limit. Fix: `Infinity` for "no cap", and refuse (or reject in `validateRunOptions`) a 0. Give both options one zero semantics in the Eval docstring.
- **(unverified) Minor, efficiency/docs:** `CHANGELOG.md:84`. "≤ ~72ms through Eval at the 64KB cap, hostile shapes included" is false for `[` (~1.1s), and for B-1/M-1 by orders of magnitude. Fix: re-measure after the fixes, and scope the claim to "the shapes in `src/admission.test.ts`", ideally using a worst-case time the test prints.
- **(unverified) Nit, dx:** `src/lang/parser-params.ts:267`. The depth refusal uses `locAt(ctx.originalSource, 0)`, so every refusal reports 1:0. The removed pre-scan pointed at the offending paren. Fix: carry a base offset in the recursive ctx.
