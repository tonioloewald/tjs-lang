## Blockers (2)

### B1 — `collapseUnions` silently truncates every sibling after a nested `|`, and it is in the published package
`src/lang/emitters/js-tests.ts:1117` — **verified, reproduced at HEAD and in `tjs-lang@0.13.0` from the registry.**

The no-top-level-union rebuild branch hands the *entire* bracket body to `collapseUnions`, which splits at the first depth-0 `|` and returns only the left side. Everything after the union inside that bracket is discarded.

```
function cfg(o: { mode: 'a' | 'b', other: 1 }): 1 { return 1 }   → THROWS
function h(o:   { other: 1, mode: 'a' | 'b' }): 1 { return 1 }   → PASSES
function tag(xs: ['yes' | 'no', 'x']): 2 { return xs.length }    → THROWS ("Expected 2 ... got 1")
function f(xs:   ['a' | 'b', 'c']): 1 { return 1 }               → passes SILENTLY with args [["a"]]
```

Whether a file compiles depends on the **order of members in an options object**. Blast radius is `tjs check`, `tjs emit`, `tjs run`, the playground and every programmatic consumer. The array case is a *new* silent failure: at base it threw loudly, at HEAD it passes with a truncated signature-test argument, so coverage is dropped without a signal.

Every nested case in `src/lang/literal-union.test.ts` uses a single-member container, so the whole multi-member class — the ordinary shape, and the one CHANGELOG's "Nested literal unions" entry claims to fix — is untested and the suite is green.

**Fix:** in the rebuild branch, split the bracket body into top-level elements first (`splitTopLevel(inner, ',')` over the masked view — already in `src/strip-comments.ts`), collapse each independently, rejoin preserving separators. Then add multi-member rows to `literal-union.test.ts` in **both** orders, plus an array case where the collapse must not change length. Ship as **0.13.1**, and soften the CHANGELOG's "Nested literal unions" claim to what actually shipped.

### B2 — `src/lang/perf.test.ts` "intensive inner loop overhead" times out; the fix exists but is **uncommitted**
`src/lang/perf.test.ts:278` — **verified.**

At commit `3ed8b75`, `bun run test:fast` (CI step 3) exits 1: the test does ~300M inner iterations with no `SKIP_BENCHMARKS` guard and no per-test timeout, and exceeds bun's 5s default under parallel load (6.4–6.7s measured, three runs). Run alone the file passes in ~800ms, which is what let it hide.

**Current state:** the working tree carries an uncommitted rewrite (`CALLS = 5_000`, local `bench()`, an apparatus docstring pointing at `bun run bench` for authoritative numbers). I ran the lane with it: **4152 pass / 32 skip / 0 fail, 21.88s.** The fix is correct and the docstring is the right shape. It is simply **not committed** — so the reviewed commit, and any tag cut from it, is red. Commit it before anything else lands.
