## Fix before the tag (majors)

1. **The `findDocCommentSpans` / `blankDocComments` scan is quadratic and unmetered on the AJS path before fuel applies, and is now a public export (#3604).** Verified (security). `src/strip-comments.ts:686-740`.
   - When an opener fails, the scan advances `i` by only 1 after scanning toward EOF, and `insideLiteral` runs `regions.some` once per opener.
   - Measured with `'/#'.repeat(k)`: 8KB 22–62ms, 32KB 260–910ms, 64KB 918ms, 128KB 28s. It runs in `parseAgentSource` before any meter.
   - Today's exposure: the 8KB default cap on `vm.run(source)`, `Eval` and `SafeFunction` limits it to about 60ms. A host that raises `maxSourceBytes`, or calls `transpile()` directly with no cap, gets super-linear work before any budget applies. tosijs-ui now runs it in the host page.
   - **Fix:** after a failed opener, move `i` past the region already scanned, and walk the sorted literal regions with a cursor.
   - **Clears when:** a linearity row that counts work (not wall time, B-2(b) style) for `'/#'.repeat(n)`, `'/#\n'.repeat(n)` and `"'a'/#".repeat(n)` on the AJS path fails with the fix reverted. Literal-blindness rows stay green.

2. **The #3608 self-call rewrite fires when the class name is shadowed inside the class body.** Unverified by the lens's skeptic. I reproduced it in triage: `class Box { constructor(v: 0){…} m(){ const Box = x => x*10; return Box(2) } }`, then `Box(1).m()` throws `Box.__tjs_callable is not a function`; rc.9 returned 20. I deduplicated the correctness major and the security minor into this item.
   - The lens reports five shadowing forms with the same result: local `const`, destructured param, default param, inner `function Box(){}`, and `catch (Box)`. The walk only skips plain Identifier params.
   - The gate is a raw-source `includes("Name, '__tjs_callable'")`, so it is also literal-blind.
   - This breaks legal JS in `.tjs` (TJS ⊇ JS). `src/lang/emitters/js.ts:~2183` / `:222`.
   - **Fix:** resolve the callee through scope analysis (bindings from declarations, every param pattern, and catch params between the call and the ClassBody). Key the "wrapper exists" check on `wrapClassDeclarations`' output set, not on a source substring.
   - **Clears when:** `class-method-validation.test.ts` has a row for each of the five shapes plus a literal-blindness row, and those rows fail with the fix reverted.

3. **`prelude: 'import'` with `runTests: true` makes every signature example and test block inconclusive.** Unverified by the lens's skeptic. I reproduced it in triage: `tjs('function add(a: 2, b: 3): 0 {…}', { prelude: 'import', runTests: true })` does not throw (inconclusive: `__tjs_createPrelude is not defined`), while `prelude: 'inline'` throws. So `tjsPlugin({ runTests: true, sharedPrelude: true })` builds green with a wrong return example, which disables the check #3599 exists to provide. `src/bun-plugin/build-plugin.ts:36`, `transpileToJS`.
   - **Fix:** always run tests against the inline form, or inject `createPrelude` into the test scope.
   - **Clears when:** a build-plugin test with both options on expects the bad example to fail the build, and fails with the fix reverted.

## Follow-ups to file

### `TODO.md` / Virta board (correctness, security, blast-radius)

- [ ] **AJS typed default fails open (#3596 leak via shared parser-params).** Verified, minor.
  - `function f(n: number = 5)` was a syntax error on AJS in rc.9. Now it emits inputSchema `{n:{}}`, which admits `'x'` and `{a:1}`.
  - `s: string = 5` is accepted silently, whereas TJS refuses it.
  - `mode: 'read'|'write' = 'read'` emits `{type:'string'}`, which admits `'drop-all'`.
  - Fix: gate the branch on the AJS path (refuse it), or carry the type into inputSchema in `src/lang/emitters/ast.ts`. Add a "typed default" row to the CONSTRUCTS/KNOWN_LEAKS ratchet in `src/lang/eval-no-transpile-execution.test.ts`.
  - Residual risk: the author's declared input contract is dropped silently. VM isolation is unaffected.
  - Re-review scope: security plus correctness over the remediation diff.
- [ ] **The `__why` explanation path costs O(n·depth) on a rejected recursive value.** Verified, minor. Measured 32–42× the accept cost, bounded at about 64× by the depth cap. `src/lang/emitters/js.ts:615`. Fix: descend without the per-level `__match` pre-check, or cap the nodes visited and fall back to the plain message. Add a work-counting row to `nested-mismatch-path.test.ts`. Residual risk: an attacker can choose a rejection that costs a bounded multiple of the check. No deployed `functions/` code uses declared Types.
- [ ] **Class-method validation silently skips bodies whose return the host discards** (`attributeChangedCallback(name='', old='', value='')` with `old = null`). Verified, minor; this is the intended semantics, it is logged in the flight recorder, and it applies to native `.tjs` only.
  - Add a BREAKING note to the CHANGELOG with this example and the `= null`, `:?` and `/* unsafe */` spellings that avoid it.
  - Consider extending the setter exemption to platform callbacks (`attributeChangedCallback`, `connectedCallback`, `handleEvent`, …), or adding a lint rule for string-example defaults on those names.
- [ ] **The generated .d.ts drops `static` and loses typed-default types on methods.** Unverified, minor. `Box.of(2)` gives TS2339 under `tsc --strict`, and `set(x: 0 = 1)` emits `set(x: any)`. `src/lang/emitters/dts.ts`. Fix: emit `MethodDefinition.static`, and route method params through the function path's typed-default handling. Add a `dts-compiles` row that calls a static method from TS.
- [ ] **`serializeType` copies a hand-maintained field list.** Unverified, minor. This is the second fix of the same class, and `destructuredParams` is still dropped from the emitted `__tjs`. `src/lang/emitters/js.ts:3505`. Fix the class: iterate the descriptor's own keys with an explicit exclusion list, or add a `keyof TypeDescriptor`-typed table test that fails to compile when a field is added.
- [ ] **The `prelude: 'import'` publish constraint is undocumented for users.** Unverified, minor. Output from it locks to an exact tjs-lang version, and a consumer whose tree dedupes `tjs-lang/prelude` gets "compiled against prelude X" at load. Add one sentence to the CHANGELOG and to the option docs (TJS-SYNTAX): the output is for a bundle built by the same tjs-lang, and must not be published unless tjs-lang is pinned exactly. Optionally warn when it is used outside the build plugin.
- [ ] **The `.tjs` → `.js` specifier rewrite happens only in the CLI** (`rewriteTjsSpecifiers`, `src/cli/commands/emit.ts:187`). Unverified, nit. Export it from `tjs-lang/lang`, or add a `specifiers: 'js'` emit option, so build scripts that call `tjs()` directly get tosijs-native's finding-5 fix too.
