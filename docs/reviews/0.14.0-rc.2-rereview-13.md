## Blockers

### B1: `admitGuestSchema` screens `pattern` only when the value is a string, so arrays and regex objects bypass it (correctness and security; verified)

`src/vm/runtime.ts` ~2849. The check is `k === 'pattern' && typeof d.value === 'string'`. Any other value is pushed onto the walk and allowed through. tosijs-schema validates with `if (o.pattern) v(o.pattern, …)`, and `v` calls `new RegExp(e, r)`, which applies ToString to whatever it receives. So `['^(a+)+$']` compiles as `^(a+)+$`, and a guest regex literal `/(a+)+x/` (which the VM's linear engine accepts) compiles on V8.

Measured with fuel 10 and timeoutMs 10 to 50:

- **inputSchema** (AST): 377 ms at n=27. This runs before fuel or the timeout exist, and `fuelUsed` is 0.
- **return-step schema**: 127 ms at n=25.
- **`Schema.isValid(s, {type:'string', pattern:[p]})`**: 123 to 364 ms, returning `{ok:false}` with no error.
- **`filter({x:s}, {…pattern:[p]})`**: 129 ms.
- **`Schema.isValid(s, {pattern:/(a+)+x/})`**: 10.6, 31.8 and 118.5 ms at n=22, 24 and 26.
- **builder `meta({pattern:[…]})` → `.validate`**: same predicate, same bypass.

Each run is exponential in input length and is reproduced on both `tjs-lang/vm` and `tjs-lang/vm-ast`. This is rereview-12 B1 again, through the value's type instead of a missed call site.

**Fix direction** (the remediating agent should plan this before patching, per the cycle flag):

- Refuse the `pattern` key whatever its value type. The only exception is `typeof v === 'string' && LIBRARY_PATTERNS.has(v)`.
- Audit every other keyword tosijs-schema coerces or looks up by value, and screen each by key rather than by value type. That includes `format` that is not in `ENFORCED_FORMATS`: `'__proto__'` and `'constructor'` reach Object.prototype members.
- The underlying question for the plan: the gate screens a *denylist of value shapes* in front of a library that coerces. Consider a closed **allowlist** of keyword → value-type pairs, or validating guest schemas on the VM's own engine.

**RE-REVIEW SCOPE:** security and correctness over `admitGuestSchema` and the remediation diff, plus a re-run of `regex-doors-behaviour.test.ts` with the widened corpus (M2), mutation-checked by reverting the guard.

## Remediation plan (round 9), written before acting

**Root cause.** `admitGuestSchema` was a DENYLIST of value shapes (`pattern` as a string, two other
keys) in front of a library that COERCES (`new RegExp(o.pattern)` takes an array or a regex
object just as happily). Denylists in front of coercing code are the same uphill shape as the
predicate verifier. The property to hold: a guest schema means only what the VM has decided it
may mean.

**Structural change: a closed schema dialect (an ALLOWLIST).** A guest schema must be a plain
JSON tree whose every keyword is in a fixed table, each with an exact value type, derived from
what tosijs-schema actually enforces (`ENFORCED_KEYWORDS`, `KEYWORD_SHAPES`, `ENFORCED_FORMATS`):

- `type` (a known type name, or an array of them); `properties`, `items`, `additionalProperties`,
  `anyOf`, `oneOf` (schemas); `required` (strings); `enum` / `const` (JSON primitives); numeric
  bounds (finite numbers); `format` (only `ENFORCED_FORMATS`, all linear: anchored fixed-width
  regexes or `new URL`); `pattern` (only the library's own strings, by identity of text);
  `title` / `description` (strings); `default` / `examples` (plain JSON).
- Anything else — an unknown keyword, `$predicate`, `patternProperties`, a non-plain object, an
  accessor, a value of the wrong type — is refused, naming its path.
- The walk is capped (nodes, depth), because it runs before any fuel exists.

**Also:**

- **M1** the evaluator checks trust on every call and caches only compiled results; untrusted
  sources never occupy cache slots; warnings are deduplicated by a separate bounded set.
- **M2** the behavioural corpus varies how a pattern is supplied (string, array, nested array,
  regex object; under `anyOf`, `items`, `additionalProperties`), uses a per-row nonce so the
  library's pattern cache cannot hide a compile, adds an apparatus row that compiles through the
  library, and a timing backstop. Mutation-checked against reverting the allowlist to a denylist.
- **M3** the compile APIs' documentation says what the decision means: they are for source the
  caller trusts, and verification is not a sandbox (JSDoc, CLAUDE.md, docs/pattern.md,
  docs/vm-budgets.md).
- **Minors:** the trusted registry becomes a `Symbol.for` slot, type-checked; one trust-gate
  function; the refusal names the schema path; a migration note for builder and persisted-AST
  schemas; `responseFormat` schemas sent to a model are admitted too.
