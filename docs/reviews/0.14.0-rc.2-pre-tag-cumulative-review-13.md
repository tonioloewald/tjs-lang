## Blockers

### B1 (security, verified): the round-38 SharedArrayBuffer refusal can be bypassed. `src/vm/runtime.ts:797`
The membrane reads `v.buffer` and the prototype by ordinary access, but `structuredClone` reads slots. Two shapes get through:
- **(a)** A `Uint8Array` over a SAB, with an own `buffer` data property pointing to a plain `ArrayBuffer`. It is admitted (`ok:true`). The guest program reads `{a:0, b:99}` across a host write, so the shared memory is live.
- **(b)** A raw `SharedArrayBuffer` with `Object.setPrototypeOf(sab, Object.prototype)`. It falls to the plain-object branch, passes `PLAIN_PROTOTYPES`, has no own keys, and the clone shares it.

The CHANGELOG claim that a SAB view "is refused at the boundary" is false for both shapes. The committed test row covers only the honest-getter case.

**Fix:** classify by brand.
- Read a view's buffer through the intrinsic `%TypedArray%.prototype.buffer` getter, or `DataView.prototype`'s, using `.call(v)`.
- Brand-check that buffer as non-shared: the intrinsic `SharedArrayBuffer.prototype.byteLength` getter must throw on it.
- In the plain branch, probe every slot-bearing brand that structuredClone serializes (ArrayBuffer, SAB, Map, Set, Date, RegExp, Error, the wrapper types) and refuse any hit as `'shape'`.
- Add rows for an own-`buffer` shadow and for a prototype-swapped SAB, each asserting the host write is unseen.

### B2 (correctness, verified): a view is charged at its view byteLength, but the clone copies the whole backing buffer. `src/vm/runtime.ts:806`, and the heap walk at `:3805`
`membraneValue({ v: new Uint8Array(new ArrayBuffer(50_000_000), 0, 1) }, 1024)` returns `ok`, `bytes=43`, and the cloned `.buffer.byteLength` is 50,000,000. The heap reconcile walk makes the same mistake, so `maxHeapBytes` misses it too. End to end, repeated crossings grew RSS by about 1.5GB under a 1MB heap ceiling. The comment directly above the code says "charge the REAL backing size". Per project rules, the fact that this predates the diff does not defer it.

**Fix:**
- Charge `buffer.byteLength`, read through the intrinsic getter, and record the buffer in `seen` so several views over one buffer are charged once (structuredClone preserves that sharing).
- Use one sizing helper for both `:806` and `:3805`. The two copies have already drifted together.
- Decide what to do with resizable buffers (`maxByteLength`): charge the maximum, or refuse as `'shape'`.
- Add rows built from `transpile()` output: a small view over a large buffer is refused for size, and repeated held views trip the heap ceiling.

### Plan required before patching (cycle stop)
B1, B2 and M1 should be fixed together as **one brand-based classify-and-size helper**, used by the inbound membrane, the run-args path, the heap walk and the other egress sites. Pair it with an apparatus row that **enumerates every structuredClone-serializable brand** and asserts that each one is either walked with intrinsic sizing or refused. Without that, the next slot type gets through the plain branch the same way. Re-review scope: security plus correctness over `membraneValue`'s classification branches and the heap-walk sizing.

## Major (fix in the same remediation)

### M1 (security, verified): an own `byteLength` or a swapped prototype defeats the OOM guard for slot-bearing values. `src/vm/runtime.ts:807`
Each of these was admitted at `membraneValue(v, 1024)` and then crossed in full:
- a 10MB `Uint8Array` with an own `byteLength: 0`
- a 10MB `ArrayBuffer` with an own `byteLength: 0`
- a 10MB `ArrayBuffer` whose prototype was set to `Object.prototype`
- a 20k-entry `Map` whose prototype was set to `Object.prototype` (the entries are never walked)
- a prototype-swapped RegExp or Error, which arrives as a real instance

This is the same class as the Map-subclass iterator bypass that the code comment documents. Run args (`argsMaxBytes`) share this path. Only host code can produce these shapes, which is the hostile-capability threat the membrane exists for. Fix it as part of the brand-helper plan above.

## Round 39 — plan (written before any code, per the cycle STOP; amended)

**Tonio's decision (2026-10-04): the membrane BUILDS its copy. JSON plus Date; no
`structuredClone`.** A first draft of this plan kept `structuredClone` and patched it; Tonio's
pick of that option was accidental and he corrected it. Considered and declined: `filter()` from
tosijs-schema. It returns `any`-typed positions uncopied, and **tosijs-schema may not be a
dependency of the membrane in any case: the VM will eventually be a dependency of tosijs-schema**
(Predicate as data runs on it), never the reverse.

**The underlying problem.** The walk classified and sized a value by its SURFACE, while
`structuredClone` copied its INTERNAL SLOTS: a shadowed `buffer`, a swapped prototype, a small view
over a large buffer, an own `byteLength`. Patching each shape left two representations to keep in
agreement. Building the copy from exactly what was read removes the second representation:
**checked = forwarded, by construction**, and the size charged is the size of what was built.

1. **`membraneValue` walks AND copies in one pass**, reading every value ONCE (own data
   descriptors; never a getter):
   - primitives (all numbers, strings, booleans, null, undefined) are copied as themselves;
   - plain objects (prototype `Object.prototype` or `null`) are copied with own enumerable
     string-keyed data properties, written with `defineProperty` so a key named `__proto__` is an
     ordinary property; a null prototype is preserved;
   - arrays are copied with their holes and non-index own properties (as `structuredClone` kept
     them), keeping the existing early bails;
   - a `Date` is recognised by BRAND (intrinsic `getTime`, which cannot be shadowed) and copied
     as a fresh `Date`;
   - shared references and cycles are preserved through a memo (as `structuredClone` preserved
     them), and a repeated reference costs one slot;
   - ANYTHING ELSE is `'shape'`: functions, symbols, bigints, accessors, Map, Set, typed arrays,
     ArrayBuffer, SharedArrayBuffer, DataView, RegExp, Error, wrappers, platform objects,
     anything with another prototype. JSON cannot express them.
   - Depth and size limits as now (`'limit'`).
2. **Charging:** the copy is built inside the budget, which egress already derives from the
   remaining fuel, and `admit` charges it at the end. So allocation is bounded by what the run
   can pay, though no longer strictly charged before it exists. This is stated in the docstring
   and vm-budgets.md.
3. **The heap walk's view sizing** stops mattering, since views can no longer enter guest state.
   A row pins that.
4. **Rows:**
   - every brand the old path admitted or mis-sized, each with its disguises (a SAB view with a
     shadowed `buffer`, a prototype-swapped SAB, ArrayBuffer and Map, an own `byteLength`, a
     small view over 50MB, a Blob behind a swapped prototype), all refused as `'shape'`;
   - plain data, null-prototype objects, sparse arrays, cycles and shared references, Dates
     (including a subclass and a prototype-swapped Date, copied by brand) crossing as before;
   - a `__proto__` key staying data;
   - the copy never being the input (identity), at every depth.
   - The existing membrane-budget and membrane-invariant suites must stay green; where a row
     relied on Map, Set, typed arrays, RegExp or Error crossing, it changes to expect a refusal,
     and the change is listed.
5. **Docs:** CHANGELOG (breaking: what crosses is JSON plus Date), CLAUDE.md (security model),
   DOCS-AJS (custom atoms), vm-budgets.md; memory records the dependency direction.

Re-review scope: security + correctness over the new `membraneValue` and every crossing.

## Round 39 — implemented (2026-10-04)

- **The membrane builds its copy** (Tonio). `membraneValue` checks and copies in ONE pass. Each
  value is read once from an own data descriptor, and its copy goes into a slot (`put`) queued
  with it.
  - Plain objects (prototype `Object.prototype` or `null`, preserved) are copied with
    `defineProperty`, so `__proto__` stays data, and keys are pre-defined in source order, so
    the LIFO fill keeps key order.
  - Arrays keep holes and non-index own properties, with the same two-scan early bails.
  - `Date` is recognised BY BRAND (intrinsic `getTime`) and copied fresh.
  - Shared references and cycles are preserved through a memo.
  - Everything else is `'shape'`.
  - No `structuredClone` anywhere in the membrane (a source-level assertion in
    membrane-invariant).
- **Every review-13 disguise, as rows:**
  - a SAB view with an own `buffer` shadow is refused;
  - a prototype-swapped SAB, ArrayBuffer and Map are read as the empty plain objects they
    present and copied as `{}`, so their slots never cross, at a cost under 1KB;
  - a 1-byte view over 50MB is refused;
  - a Blob, RegExp, Error, typed array, Map and Set are refused;
  - Dates (a subclass and a prototype-swapped one included) arrive as fresh intrinsic Dates;
  - the copy is never the input, at any depth, with cycles and sharing preserved;
  - a `__proto__` key stays data;
  - holes and key order are kept;
  - a `structuredClone` stub that throws changes nothing.
- **Old-contract rows changed, listed:**
  - malicious-actor: "an ordinary Map still crosses" became "is refused"; "small
    binary/collection payloads pass through" became "are refused"; the budget row expects a
    KIND refusal for binary/collection types and a budget refusal for the plain array;
  - args-membrane: Map removed from the crossing row, with a Map-refused row added;
  - egress-cost: the Map/Set bail rows became "refused by kind without reading an entry", and
    the shared-value Map/Set shapes left the early-bail table;
  - membrane-invariant: its positive control asserted the Map/Set intrinsic iterators and now
    asserts `readArrayData` and the Date brand instead;
  - membrane-doors lost its stale `structuredClone`-error allowance; guest-key-writes allows
    `defineData` with its reason.
- **Mutants caught:** forwarding the input instead of the copy, the plain-prototype check off,
  assigning instead of defining (`__proto__`), no memo for shared refs, Date by `instanceof`.
- **Found on the way, carded (#2877):** a TJS literal-blindness bug. An apostrophe inside a
  comment inside a parameter list breaks the paren transform (valid TJS fails to transpile), in
  ~6 hand-rolled quote scanners in `parser-params.ts`. A doc comment in this round tripped it
  through admission.test.ts's TransformWork row; the comment was rephrased here and the parser
  fix is the card. Also: `new Date(...)` → `new globalThis.Date(...)`, the file's idiom, so
  runtime.ts still graduates to native TJS (dogfood 127/127).
- **Docs:** CHANGELOG (breaking: JSON + Date only), CLAUDE.md (membrane, Custom Atoms Must),
  DOCS-AJS (capability returns, Set), vm-budgets.md.
- **Lanes:** lint, typecheck, make, test:fast (7381), dogfood, and the full suite without the live
  LLM (7379, 0 fail).
