## Blockers

### B1. Membrane array copy seeded from an unchecked Proxy `length` (security, confirmed)
`src/vm/runtime.ts:965–984`, `readArrayData`:

```ts
const len = v.length            // [[Get]]: runs a Proxy get trap
const copy: unknown[] = Object.setPrototypeOf(new Array(len), null)
```

If `len` is an object, `new Array(len)` becomes `[len]`. Then `Math.min(len, probeCap)` is NaN, so the index scan never runs. An `ownKeys` that returns only `['length']` empties `Object.keys`, and `holes = NaN` skips the hole charge. The walk returns `ok: true` with the host object sitting at `copy[0]`, never read, checked or copied.

The verifier reproduced this against HEAD using `AgentVM` and `transpile()` output:
1. A store capability returns `{ list: Proxy(length → hostObj) }`. The guest's `return { h: x.list[0] }` gives `r.result.h === hostObj`, which is true.
2. With a host array as the lie, `x.list[0].push('guest')` mutates the host array in place.
3. Passed as a `vm.run` argument (so also Eval context and SafeFunction args), `result.same === hostObj` is true.

A function used as the lie is still caught downstream by the guest-value domain. Plain objects and arrays are not caught. The membrane's own documentation names hostile or broken capabilities and Proxy traps as in scope.

The `new Array(len)` read predates the base. It is a blocker anyway: per project policy, "predates" is not a reason to defer, and round 41 rewrote this exact line.

**Fix:**
- Read `length` from its own data descriptor and refuse with kind `'shape'` unless it is an integer in [0, 2^32−1].
- Never pass an unvalidated value to the `Array` constructor.

**Tests to add** in `membrane-halt.test.ts`, for both capability returns and run arguments:
- Lying traps: `length` returns an object, a function, a string, NaN, or 2^32.
- A `getOwnPropertyDescriptor` / `ownKeys` pair that disagrees with `get`.
- Assert no host identity in the result and no host mutation.

**Re-review scope:** the security lens over all of `readArrayData` / `membraneValue`, looking for every remaining [[Get]] or coercion of a host value inside the walk. Then correctness and blast radius over the remediation diff.

## Round 43 — plan (written before any code, per the cycle STOP)

**The underlying problem.** The membrane's rule is "read the walked value only through own data
DESCRIPTORS, and copy only what was read and walked". `membrane-invariant.test.ts` enforces part
of it (no `v[k]` and no `for…of v` inside `membraneValue`), but not ordinary property reads such
as `v.length`, and it does not scan the helpers (`readArrayData`, `readOwnData`) at all. B1 is
`v.length` read by `[[Get]]` in a helper and then handed to the `Array` constructor, which
overloads on its argument's type.

1. **B1.** `readArrayData` reads `length` from its own data DESCRIPTOR and refuses (`'shape'`)
   unless it is an integer in [0, 2³²−1]. The copy is built as `[]` with that validated length
   assigned; no host-derived value ever reaches a constructor.
2. **The guard, extended to the shape of the mistake.** `membrane-invariant.test.ts` now scans
   `membraneValue` AND its helpers, and fails on ANY ordinary property read of the walked value
   (`v.x`, `v[k]`, `v?.x`), not only computed ones. Reads that must happen are made through named
   intrinsics (`Object.getOwnPropertyDescriptor`, `Object.getPrototypeOf`, `Array.isArray`,
   `Object.keys`) or allowlisted with a reason. It has an apparatus row (planted reads must fail
   it).
3. **Rows:** lying-Proxy `length` (an object, a function, a string, NaN, 2³², a descriptor that
   disagrees with `get`) for capability returns AND run arguments, with no host identity in the
   result and no host mutation.
4. **M1:** capture `Date.prototype` and the intrinsic `getTime` at load, beside `MembraneDate`,
   and use only those. Row: replacing `globalThis.Date` with a subclass changes nothing.
5. **M2:** object copies are built on `{}` (or `Object.create(null)` when the source had a null
   prototype), with `Object.defineProperty` for every key: own data properties, no inherited
   setter, and in V8's fast mode. Arrays keep the null-prototype build and get their prototype
   when complete; checked in V8, and switched if they also fall to dictionary mode. A `node`
   subprocess row checks `%HasFastProperties` on copies.
6. **N1:** correct the stale `egressValue` comment. **N2 / M3:** already carded; the
   optional-globals lesson goes into review-lenses.md and is flagged for the shared practices.

Re-review scope: security over every read of a host value in the walk; correctness + efficiency
over the remediation diff.
