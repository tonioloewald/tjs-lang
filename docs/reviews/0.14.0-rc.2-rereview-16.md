## Blockers (verified)

### B1. Argument reads are a guest-value producer that bypasses the choke point (correctness and security, merged)
`src/vm/runtime.ts:1391-1392` (`resolveValue`, `$kind:'arg'`) and `:1317-1318` (`resolveName`, the `args.` branch) both read `ctx.args[path]` directly. There is no own-property check, no FORBIDDEN_PROPERTIES check and no `guestValue` call. `ctx.args` is an ordinary `{}`. `varsImport` (`:5353`) goes through the same path.

Reproduced at 53a54d8 on a plain AgentVM:
- v2 `{$kind:'arg', path:'constructor'}` delivers the host `Object` to an io sink, and `return {v: …}` puts `result.v === Object` on the host.
- v1 `'args.toString'` and `varGet args.constructor` do the same.
- `varsImport {g:'hasOwnProperty'}` stores a host function in state, and from there it reaches the sink and `result`.
- `varsImport {p:'__proto__'}` hands a capability **`Object.prototype` itself**. Any capability that writes to its input then pollutes every object in the host.
- Legitimate source breaks too: `function f(toString = 1) { return { v: toString } }` fails with "A function or builtin namespace is not a value" instead of applying the default.

**Fix:** read with `ownValue(ctx.args, key)`, check the forbidden key, and wrap the result in `guestValue`. Build `args` with a null prototype at admission (vm.ts post-membrane, callLocal helper args, both agentRun child contexts). Structurally, put the check where values **become** guest state (`setStateVar`, the atom-result bind in `exec`, io-atom input resolution), not only on `evaluateExpr` results. Add ratchet rows for v1 and v2 `$kind:'arg'` with `constructor`, `toString`, `valueOf`, `__defineGetter__` and `__proto__`, for `'args.X'`, and for varsImport with an inherited alias. Each row should assert that nothing reaches state, the sink or `result`. Add a source row for `function f(toString = 1)`.

### B2. `pick` harvests the sealed (non-enumerable) methods of wrappers (security)
`src/vm/runtime.ts:5954`: `pick` uses `ownValue`, which ignores enumerability. Reproduced in v1 and `$ajs:2`:
- `pick(Set([1]), ['add','has'])` delivers the live host closures, bound to the run's heap and state, to an io sink and into `result`.
- Date wrappers (`add`, `format`) and regex (`toString`) behave the same way.

Calling the stolen function inside the guest is reportedly closed by `intrinsicMethod`; that was not verified. Even if it is, the result breaks the decision that "a host function is never a guest value", through an atom RESULT, which the round-11 plan wrongly said was inherited from expressions.

**Fix:** make `pick` (and its siblings) read only enumerable own data and run each value through `guestValue`, or refuse wrapper receivers. Better, the deep bind-time check from B1. **Re-review scope:** enumerate every core and battery atom RESULT (pick, omit, merge, keys, find, map, filter, reduce, regexMatch, jsonParse, xmlParse, memoize, cache, varGet, varsExport, callLocal, agentRun, runCode) against wrapper and args receivers.

### B3 (reproduced by the completeness lens, NOT skeptic-verified; fix with the blockers). `countPaths` validation can hang synchronously
`src/vm/vm.ts` admission: `countPaths` dropped `countNodes`'s WeakSet, and `affordable` is unbounded. The lens reproduced:
- **Hang:** `function f(x: { a: 0 })` with cyclic args (`a.self = a`) and `fuel: Infinity` blocked the event loop until the process was killed after 15s. The timeout timer never existed.
- **Finite fuel:** the synchronous work grows with fuel (335ms at 1e5, so roughly 30s at 1e7). DAG args behave the same way.

**Fix:** cap the count absolutely (or by args bytes), and decide whether cyclic args are admissible at all. Add a row that would catch this.

## Major (verified)

- **M1. Wrapper sealing turned a loud refusal into silent data loss** (`runtime.ts:1596-1608`, `sealMethods`). A Set passed through `agentRun` returns `{"got":{"size":3}}`; at 79f9907 it was refused. `structuredClone(result)` of a Set is `{size:3}`, and a Date becomes a bag of fields. That matters for exactly the worker or separate-process hosts the 0.14.0 security model recommends. **Fix:** at every clone boundary (membrane args and returns, the run result), turn a wrapper into data (Set → array, Date → ISO string or timestamp, as `toJSON` already does) or refuse it loudly. Add rows for agentRun/runCode round-trips and `structuredClone(result)`. This is the same decision as the ratchet item below.

## Remediation plan (round 12), written before acting

**Root cause.** Round 11 checked values where EXPRESSIONS produce them; the review found
producers that are not expressions (argument reads, atom results such as `pick`). Enumerating
producers is the uphill shape again. Values only matter where they ENTER guest state or LEAVE the
VM, and those points are few and already funnelled.

1. **The domain check lives in the bind measurement.** Every scope write goes through
   `setStateVar` (pinned by `state-writes.test.ts`), and every bound value is walked by
   `estimateBytes` to charge it — or, past the walk's cap, by the full reconcile over all roots;
   a mutation charges what it inserts the same way. That walk now refuses a host function or a
   builtin namespace anywhere in the value (a VM wrapper's own sealed methods excepted). One walk
   charges and checks, so the check cannot be skipped by a producer nobody listed.
2. **Arguments are data with no prototype.** Run arguments (and helper/child-run arguments) are
   null-prototype after admission; every argument read is an OWN read, forbidden-key checked and
   passed through `guestValue`.
3. **Defense in depth:** `pick` and siblings read enumerable own data only.
4. **Egress converts wrappers to data** (Set → array, Date → its ISO form, regex → its source) at
   the run result and at child-run boundaries, so a clone never silently drops one (M1).
5. **`countPaths` is capped absolutely** (and cycles cannot hang it; B3).
6. **The ratchet's apparatus sees non-enumerable functions**, and gains rows for argument reads,
   atom results (`pick` of a wrapper), v1 references, child-run round-trips and
   `structuredClone(result)`; the untested calibration and 3MB `isValid` rows are added.
