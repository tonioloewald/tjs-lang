## Blockers

### B-1 (security, severity major, verified). `extractReturnTypeValue` scans to EOF for each candidate, so the AJS preprocessor is quadratic under the cap
- **Where:** `src/lang/parser-params.ts:1299` (`extractReturnTypeValue`), called from `transformParenExpressions` at about line 972.
- **Mechanism:** Every balanced `(…)` followed by a `:` that is not in `ternaryColons` calls `extractReturnTypeValue(source, j)`. In that function, the bracket-depth branch runs before the check for a depth-0 `{` body. With unbalanced `{`, `[` or `(`, depth never returns to 0, so the scan walks to EOF once per candidate. When no `=>` follows, the result is discarded.
- **Evidence (reproduced on HEAD):** `Eval({code, fuel:10, timeoutMs:1})` at 60KB: `():(` 1889ms, `():[` 1776ms, `():{` about 1.8s, `(): x | {` 1174ms. `(): {` scales 84ms → 361ms → 1477ms over 15, 30 and 60KB, about 4x per doubling, so the cost is quadratic. The single tokens alone are linear (28ms and 9ms). Every run ends in a parse error, so none of that time is charged to fuel, the timeout or the deadline.
- **Reach:** Eval, SafeFunction, `vm.run(source)`, and runCode/transpileCode, which back the hosted endpoints. Anyone who submits AJS source can cost about 2s of CPU per request.
- **Why the tests missed it:** the generated grid repeats single tokens only, and this cost appears only for the pair (opener token followed by an unbalanced bracket).
- **Also:** this makes the "worst ~111ms" in `CHANGELOG.md:88` and `src/lang/eval.ts:184` false.
- **Fix direction:** make the return-type scan bounded or linear. Options:
  - Bail at an unbalanced bracket or a newline.
  - Cap its extent.
  - Memoize per start index in the frame, like parenMemo/classBodyMemo.
  - Jump to the partner proven by parenMemo.

  Add admission rows for `():(`, `():[`, `():{` and `(): x | {`. Extend the generated grid to token **pairs**: the opener tokens (`():`, `(a): `, `=>`) crossed with each bracket or literal opener. Re-state the worst-case figure.
- **Re-review scope:** efficiency + security over the remediation diff. Re-run the pairwise grid through Eval with a 15/30/60KB scaling check, not a single bound.
