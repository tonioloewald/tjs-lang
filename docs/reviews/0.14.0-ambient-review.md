## Blockers

### 1. The ambient `continue` in fromTS drops `declare interface` and `declare type` (correctness, verified)

**Where:** `src/lang/emitters/from-ts.ts:3760`

**The defect:**
- The new rule at the top of the statement loop skips every statement that has a `declare` modifier. Only `ClassDeclaration` is exempt.
- For `InterfaceDeclaration` and `TypeAliasDeclaration`, TypeScript treats `declare` as redundant: it adds no ambient meaning.
- fromTS deliberately promotes those two kinds to runtime `Type`s. For them the `Type` *is* the metadata. So the commit message and CHANGELOG claim "one rule, for every statement kind … metadata survives" is false for these kinds.

**Reproduced by the verifier:**
- Base is `c42a689`, from `git archive` into a scratchpad. HEAD is the working tree.
- `export declare type Bar = { b: string }`:
  - base emits `export Type Bar { example: { b: '' } }`
  - HEAD emits nothing
  - so `import { Bar } from './that-file'` now fails to link
- `declare interface Foo { a: number }` together with `export function f(x: Foo): number`:
  - base emits `Type Foo { example: { a: 0.0 } }`
  - HEAD drops it, while the TJS output still says `x: Foo`
  - after `tjs()`, `f.__tjs.params.x.type.kind` changes from `declared` to `any`
- Control: `export type Baz` without `declare` still emits `export Type Baz` at HEAD. The regression is isolated to the new skip.

**Collateral:** the skip also bypasses three things for these statements:
- `seenTypeNames`
- `annotationMap`, which holds `@tjs-skip` and the other annotations
- the value-name collision comment

**Why no gate caught it:**
- The new tests cover only `declare function`, `declare enum`, `declare const enum` and `declare const`.
- None of the corpora contains an ambient interface or type alias.

**Fix, choose one:**
- **(a) Preferred, since it matches the existing pattern:** exempt `InterfaceDeclaration` and `TypeAliasDeclaration` from the ambient skip, the same way `ClassDeclaration` already is. They then go through the ordinary interface and type-alias branches.
- **(b) Narrower rule:** skip only the kinds whose `declare` form differs at runtime: `FunctionDeclaration`, `EnumDeclaration`, `VariableStatement` and `ModuleDeclaration`.

**Before fixing:** add a reproduction test first, per the bug-fix rule. Put rows in the "ambient STATEMENTS emit no code" test asserting that:
- `declare interface Foo {…}` still emits `Type Foo`
- `export declare type Bar = …` still emits `export Type Bar`
- `f.__tjs.params.x.type.kind` is `declared`, not `any`

**Also required:**
- Correct the CHANGELOG wording ("one rule, for every statement kind") so it names the exempt kinds.
- Update the `STATUS: CLEARED` note in `docs/reviews/0.14.0-class-metadata-review.md`: that remediation introduced this regression.
- Run `bun run docs` afterwards, because `demo/docs-fresh.test.ts` fails after any CHANGELOG edit.

**Re-review scope:** correctness and blast radius, over the remediation diff only.
