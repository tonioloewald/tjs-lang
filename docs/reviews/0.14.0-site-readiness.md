# Doc site readiness (tjs.tosijs.net) — 2026-10-05

The bar for retiring the old playground (Virta #1833): every playground example RUNS on the
tosijs-ui doc site and a reader SEES its output. Measured with `scripts/check-site-examples.ts`
(headless Chrome over CDP, one full load per page) against `bun run preview:site`.

## What the first full sweep found (0f5b3ce)

116 pages, 162 live examples, 164 problems.

Fixed before the sweep (each found by trying):

- **TJS/TS examples ran a CDN's tjs-lang 0.13.13**, not this commit's: tosijs-ui skips copying
  `tjs-lang/browser` into the site, silently, when it cannot resolve it, and a fresh worktree has
  no `dist/`. The live site has this today. Fixed: `prebuild` builds the two bundles;
  `deploy-site` fails the build if they are missing (7456e17).
- **`extractTests` found zero tests** in any example opening with a `/# … #/` doc block (37 of
  them): prose in the block opened a string in the literal scanner. It also extracted a `test`
  QUOTED inside one. Fixed in tjs-lang (377a657).
- No safe local preview existed (`devServer` builds in this checkout and `buildSite` deletes
  `dist/`). Added `bun run preview:site` (a0851d6).

## Plan

In order; each fix gets a reproduction (a sweep row or a unit test) first.

1. `liveExamples: 'opt-in'`; playground example fences opt in (`tjs:inline`, `ajs:inline`,
   `ts:inline`). Prose fences stay highlighted, not run, and keep GitHub highlighting. Our own
   builder (`bin/site.ts` `firstCodeBlock`) must accept the suffix.
2. Site `tjs`/`ts` dialects (`registerDialect`, replacing the built-ins): this commit's
   transpiler, module syntax stripped.
3. `installRuntime()` in `site/entry.ts`.
4. Examples: tosijs-todo imports; async-functions logs its result; the two wasm demos render
   into `preview`.
5. `importResolver` on.
6. Multi-file examples: say on the page that they need the playground / `tjs` CLI.
7. tjs-lang: a public API that prepares inline tests the way `runAllTests` does; file
   tosijs-ui to adopt it, and to show console/test output when the preview is empty (#9).
8. Re-sweep to zero, then deploy.
