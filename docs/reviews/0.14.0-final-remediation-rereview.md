## Follow-ups

None of these was verified. Each is a lead, so sanity-check it before acting.

### Minor

- **Extend rewrite, nested `/*` (security lens, unverified).** In `src/lang/parser-transforms.ts:3857`, the backward comment skip uses `lastIndexOf('/*')`.
  - **Input:** `v./* a /* b */shout()`.
  - **Effect:** the transpile fails with `Unterminated comment`. It is TJS-only, never reaches AJS and has no execution effect.
  - **Fix:** take the dot position from the AST (scan forward from `callee.object.end` with the forward `skipTrivia`), and add a literal-blindness row.
- **Unfiled Bun workaround (blast-radius lens, unverified).** In `src/bun-plugin/build-plugin.ts:88`, the skip branch returns `{contents, loader:'ts'}`. Bun's runtime `plugin()` rejects an `undefined` return from `onLoad`, while `Bun.build` accepts it.
  - **Gaps:** there is no `UPSTREAM.md` entry and no upstream issue. The workaround also forces the `ts` loader on skipped `.mts`/`.cts` files.

### Nit

- **Extend rewrite, parenthesised callee (correctness lens, unverified).** In `src/lang/parser-transforms.ts:3951`, `((7).clamp)(0, 5)` still produces output that does not parse.
  - **Cause:** `open` lands on the `)` that closes the parenthesised callee, not on the call's `(`.
  - **Not a regression:** the base also fails, through a different mis-cut.
  - **Fix:** check that `source[open] === '('`; otherwise walk to the call's own `(` or skip the rewrite.
- **Double trailing dot (security lens, unverified).** In `src/vm/runtime.ts:1467`, `isBlockedUrl` strips only one trailing dot, so `localhost..` and similar names are classified as public.
  - **Why it is harmless today:** the name does not resolve (ENOTFOUND), and it is admitted only if the allowlist names that exact spelling.
  - **Fix:** use `.replace(/\.+$/, '')`, or refuse empty labels.

### This repo's board (Virta, project tjs-lang)

- [ ] Card: the extend call rewrite takes its positions from the AST, not from rescanning the source. This covers both the nested-`/*` minor and the `((x).m)(…)` nit. Add literal-blindness rows for `v./* a /* b */m()` and `((7).clamp)(0,5)`.
- [ ] Card: `isBlockedUrl` normalises every trailing dot (or refuses empty labels). Add a `localhost..` row to `fetch-private-network.test.ts`.
- [ ] Card: track the Bun `onLoad`-undefined divergence. Revisit the forced `ts` loader for `.mts`/`.cts`, and remove the workaround when Bun aligns the two APIs.
