## Blockers

### B1 (correctness, verified, regression): `reduceThrown` erases host-built-in error messages for the guest and the host
`src/vm/runtime.ts:5001`. Round 37 changed the reducer from `e?.message` / `String(e)` to `ownString(e, 'message')`.
- In Bun, `DOMException.message` and the abort reason are prototype accessors, and `new Error()` has no own `message`.
- A verified probe: an atom throws `new DOMException('The operation timed out.', 'TimeoutError')`. The guest `catch` binding and the host's `r.error.message` both read `'an atom failed with a value that is not a message'`. At `2730d97` they read `'The operation timed out.'`.
- `throw 42` and `class E extends Error { get message(){} }` are lost in the same way.
- Root cause: the producer site (`runtime.ts:5452`, which builds the host-facing AgentError and the recorder entry) uses the same guest-scope rule as the bind. That rule was only ever meant for the bind.
- The `|| 'Sub-agent failed'` fallbacks in agentRun (`:7352`, `:7395`, `:7424`) can no longer fire, so they are dead code.

**Fix direction:** separate "never run guest-forgeable code" (the bind) from "never read a host built-in" (the producer). At the producer, read `message`, plus `name`, from a genuine native `Error` or `DOMException`. Keep own-data-only at the try bind. Add `membrane-halt.test.ts` rows for DOMException TimeoutError and AbortError, `new Error()`, and `throw 42`, each asserting what the guest and the host see. Re-review scope: correctness plus security over `reduceThrown` and every call site. **Per the cycle flag, plan before patching.** This reducer is now in its third round, so first decide which value each consumer is owed: the guest bind, the host RunResult, the recorder, and agentRun.

### B2 (security, verified, latent): a SharedArrayBuffer-backed typed array crosses the membrane as live shared memory
`src/vm/runtime.ts:782`. `membraneValue` accepts any `ArrayBuffer.isView(v)` and charges `byteLength`, but it never checks `v.buffer` or the prototype. `structuredClone` shares a SAB rather than copying it.
- Verified repro: a store returns `{ v: new Uint8Array(new SharedArrayBuffer(8)) }` and later sets `view[0]=99`. The guest program then returns `{before:0, after:99}`.
- This contradicts the documented membrane promise and round 37's own "could plain JSON have done this" criterion. It is also a source for a high-resolution timer gadget.
- Only the host can trigger it, and it predates this diff, but it sits in the code this diff rewrote. "Predates" is not a reason to defer.

**Fix:** refuse a view whose buffer is not an intrinsic `ArrayBuffer`, and a raw `SharedArrayBuffer`, as kind `'shape'`. Require intrinsic TypedArray, DataView and Date prototypes, as the Map/Set branch already does. Add a `membrane-invariant` row: a SAB view from a capability halts the run, and host mutation afterwards is not observable.

## Round 38 — plan (written before any code, per the cycle STOP)

**The underlying problem (B1).** Round 37 reduced errors by a rule written for the wrong threat.
"Never run a getter" protects the capability-return walk from TOCTOU (a getter can answer
differently each time it is read, so the checked value and the used value diverge). An error
message is read ONCE and kept as a string, so a getter cannot make a checked value differ from a
used one. And every thrown value comes from HOST code (an atom body; a guest cannot throw an
object), so reading its own `message` runs code the host wrote, in the host. What must never
happen is a LIVE object, or an unbounded value, reaching the guest. So, one reducer for every
consumer (the guest bind, the host RunResult, the recorder, a sub-agent's failure):
- read `message` ONCE, by ordinary property access (native getters included: DOMException);
- a string is capped;
- a primitive thrown value is `String(value)`, capped (`throw 42` gives `'42'`);
- anything else is the fixed text, and an object is never `String()`ed;
- `errorOp` is the `op` if it is a string (capped), else `undefined`, as before round 37.

The forged-getter row changes from "the getter never runs" to "what the getter returns never
reaches the guest unless it is a string, and then capped". Rows: DOMException TimeoutError and
AbortError, `new Error()`, `throw 42`, a getter-message subclass, each asserting what the guest
AND the host see.

**B2.** The typed-array branch accepted any `ArrayBuffer.isView`, and `structuredClone` SHARES a
`SharedArrayBuffer`. A view must have an intrinsic TypedArray or DataView prototype and an
intrinsic `ArrayBuffer` (never shared); a `Date` must have the intrinsic prototype (as Map/Set
already must). Anything else is `'shape'`: JSON cannot express shared memory. Row: a SAB view from
a capability ends the run, and a host mutation afterwards is not observable.

**Also this round (small, in the same code):**
- A Proxy trap that throws during the walk becomes a `'shape'` refusal with what was walked, not
  an escaped exception that is catchable and unbilled. Row.
- **The error-field ratchet matches by ROLE, not by spelling.** It unwraps `as`/`!`/parens and
  `?.`, covers element access and destructuring of `message`/`op`, uses per-occurrence keys (one
  allowlist entry cannot cover a future read in the same function), and has an apparatus row and
  a stale check. The two raw reads it missed (`cause?.message` in the recorder, a cast read in
  `egressValue`) are routed through the reducer or listed. The lesson recorded in
  review-lenses.md: a ratchet that matches by spelling needs an apparatus row and a stale check.
- The clone RangeError branch gets a row (stub `structuredClone`: RangeError gives `'limit'`,
  DataCloneError gives `'shape'`).
- `reduceThrown` is marked `@internal` (it became public by `export *`); carded for an internal
  module before 0.14.0 final.

Re-review scope: correctness + security over the round-38 diff.
