## Blocker (adversarially verified)

### B-1. The recommended replacement for vm.run(source) has no source bound, and the notice says it is safe (security + correctness, `src/vm/vm.ts:253-269`)

- **What the notice says.** The recorder notice reads: "transpile separately (tjs-lang/lang `transpile`) and run the AST with tjs-lang/vm-ast, so parsing untrusted source can never take the VM host down". It does not say the parse must run in a worker, in another process or on the caller's machine. Only the code comment and the CHANGELOG say that.
- **The missing bound.** `transpile` (`src/lang/index.ts:215`, `src/lang/core.ts:38`), `ajs```, `createAgent` and `parseAgentSource` never call `sourceBytesOver`, and `transpile` has no `maxSourceBytes` option.
- **Measured on the B-2 nested-destructuring shape.** `transpile()` took 127ms at 5KB, 475ms at 10KB and 2305ms at 20KB, and 11.8s at 48KB in another run. Some shapes overflow the stack at 32KB. `ajs` at 10KB took 525ms. `AgentVM.run(src)` at 10KB was refused in 1ms.
- **Fix, both parts required.**
  1. Rewrite the recorder message (and README/DOCS-AJS, see gaps) to say where the parse must run and how to bound it. For example: "…transpile on the caller's side or in a worker/separate process; if you must transpile untrusted source in-process, cap it first (`sourceBytesOver` / `DEFAULT_MAX_SOURCE_BYTES`)".
  2. Give the recommended path the same funnel: `transpile(source, { maxSourceBytes })`, or an exported `admitSource` / `transpileUntrusted` helper from `tjs-lang/lang`. Add it to `SOURCE_ENTRIES` in `src/admission.test.ts`. It must not refuse valid trusted TJS where no cap was intended, so it is opt-in or scoped to the AJS path.
- **Re-review scope:** security + correctness over the remediation diff.

- [ ] **CHANGELOG falsely says runCode/transpileCode's cap can be "raised per call"** (confirmed; `src/vm/runtime.ts:4217`, `CHANGELOG.md` ~L20-26). `MAX_TRANSPILE_SOURCE_BYTES` is a module constant equal to the default, and neither `RuntimeContext` nor the `vm.run` options reach it.
