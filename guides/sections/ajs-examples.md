# AJS Examples

Runnable AJS agents, from first steps to multi-agent pipelines.

<!-- TODO review -->
Each chapter is one agent you can run and edit on the page, then what to notice about it, a
variation, and the place where it differs from JavaScript or where it can fail. The examples run
on the same sandboxed VM you would embed: fuel-metered, with no capabilities except those the
page grants (fetching from three public APIs). Examples that need a language model cannot run on
a static page, so they print a message and show how to run them locally.

Read in order if AJS is new to you: [Featured](/ajs-featured/) for why it exists,
[Basics](/ajs-basics/) for the language, [APIs](/ajs-api/) for the network, [LLMs](/ajs-llm/)
for models, and [Advanced](/ajs-advanced/) for agents that combine them. Afterwards you can write
an agent, run it with a budget and capabilities of your choosing, and let a model write one.
