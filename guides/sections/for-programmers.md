# For Programmers

If you already program, start here rather than with Learn to Program. Each chapter in this part
stands on its own, so read the one that matches where you are coming from:

- [TJS: Typed JavaScript](/tjs/), a ten-minute tour for any working developer: install, the
  CLI, a first file, and what TJS adds to JavaScript.
- [TJS for JavaScript Developers](/TJS-FOR-JS/): what changes when a `.js` file becomes a
  `.tjs` file, and why.
- [TJS for TypeScript Developers](/TJS-FOR-TS/): how TJS's types differ from TypeScript's, and
  how to bring a TypeScript project across.
- [Going Back](/going-back/): leaving TJS, by emitting plain JavaScript and `.d.ts` files, and
  what that costs.

The Language in Depth, the next part, covers each feature properly.
