# Advanced

<!-- TODO review -->
Agents that combine the pieces: a model that plans while code computes, a pipeline of roles,
vision models reading images, and models that write AJS which the agent then runs in the same
sandbox. All of them need a model, so here they print a message instead of running.

Read [Basics](/ajs-basics/) and [LLMs](/ajs-llm/) first. [LLM with Tool](/llm-with-tool/) is the
best place to start: its pattern, where the model decides and code does the work, recurs in all
the others.
