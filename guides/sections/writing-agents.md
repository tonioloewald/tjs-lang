# Writing Agents

An AJS agent is a small JavaScript function that a host runs inside a sandbox, with a fuel
budget and only the capabilities the host gives it. This part teaches you to write one, a step
at a time: a first agent, then values and expressions, calling atoms, decisions and loops,
errors, the contract an agent declares, and the limits every run is held to. Every example runs
in the page.
