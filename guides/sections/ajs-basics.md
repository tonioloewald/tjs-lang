# Basics

<!-- TODO review -->
The language itself, one idea per page: the shape of an agent, arithmetic, decisions, lists,
text, JSON and errors. Every example runs on this page, and every page ends with the place where
AJS differs from the JavaScript you know, because those differences are what trip people up.

Read them in order. After the last one you can write an agent that takes input, computes, loops,
handles bad data without crashing, and returns a result a host can use.
