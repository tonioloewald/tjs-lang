# APIs

<!-- TODO review -->
Agents that reach out to the world. Each calls a public API with `httpFetch` (weather, music,
code repositories), reshapes the answer, and returns only what matters. They run live here: this
site lets examples reach those three services and nothing else.

You will see how the network becomes a capability the host grants, why an HTTP error status is not
an AJS error, and how to keep a response small. Read [Weather API](/weather-api/) first.
