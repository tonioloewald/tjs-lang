# LLMs

<!-- TODO review -->
Agents that call a language model: a chat, a summarizer, and structured extraction. A static page
has no model to call, so these examples print a message here instead of running; each page shows
how to run it locally with a model server such as LM Studio.

Start with [LLM Chat](/llm-chat/), which sets up the host the others reuse. After these you can
prompt a model from an agent, cap what it may cost, and get JSON back instead of prose.
