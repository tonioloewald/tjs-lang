# Learn to Program

Programming from scratch, in TJS, in this page. You need nothing installed and no experience:
every example is a small program you can run, change and break, and each one checks its own
answer so you can see when you have it right.

## What you will learn

By the end of this part you will be able to write small programs that put words and pictures
on a page, do arithmetic, make decisions, repeat work, keep lists, describe things with
several parts, check their own answers, and respond when someone clicks a button. You also
learn what to do when a program goes wrong, and how to wait for work that takes time. The
closing project puts all of it together into a working calculator.

That is not a toy subset. Every program you will ever write is made of the same few ideas:
values and names, decisions, repetition, lists, and functions. Real programs use more of them,
in bigger combinations, but they do not use anything fundamentally different.

Some things this part leaves out: classes, modules (splitting a program across files), and
servers (programs that run somewhere other than the page). They build on the ideas here, and
the rest of the book covers them. When you finish the calculator, go on to
[Basics](/tjs-basics/), starting with [Hello TJS](/hello-tjs/). Those chapters are written for
people who already program, so they move faster, but by then that is you.

## How to read this part

Read the chapters in order. Each one uses what came before, and each is short enough to
finish in a sitting.

Do the examples, not just read them. Change a number and see what happens; change it back.
Every chapter ends with a few **Try it** exercises, done in the live examples on the page.
They matter more than the prose: reading about programming teaches you about as much as
reading about swimming.

Expect to make mistakes. Programmers make them all day; the skill is noticing and fixing
them quickly. TJS helps: it checks what kind of value each part of a program expects, and
when something does not fit it tells you what, where and why. You will see those messages
often, and by the end of the part you will read them the way you read a road sign.

If you already program, skip this part. [Basics](/tjs-basics/) is the place to start in this
book, and the [TJS quick start](/tjs/), in the separate TJS guide, is a faster overview still.
